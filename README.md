# 🍁 메이플 도우미 (MapelHelper)

MFC와 C++을 기반으로 개발된 메이플스토리 유저 편의성 향상 프로그램입니다.  
PC방 등 가변적인 환경에서도 개인 맞춤 설정을 신속하게 적용하고 안전하게 복구할 수 있도록 돕습니다.

---

## 🛠 개발 환경
- **Language:** C++
- **Framework:** MFC (Microsoft Foundation Class)
- **OS:** Windows 10 / 11

---

## ✨ 주요 기능 (현재 활성화)

### 1. 키보드 반응 속도 오버클럭 (레지스트리 편집)
- 게임 내 원활한 연타와 딜레이 최소화를 위해 필터키 속성(`DelayBeforeAcceptance`, `AutoRepeatDelay`, `AutoRepeatRate`)을 정밀하게 제어 및 실시간 적용합니다.

### 2. 원 클릭 원상복구 (리셋 기능)
- 프로그램 종료 또는 리셋 시, 초기 실행 시 백업해 두었던 PC 순정 상태(기본 키보드 설정 값)로 안전하고 완벽하게 원상복구합니다. (PC방 등 공공장소 사용 후 안전한 이탈 가능)

---

## 🚀 추후 업데이트 예정 기능 (Roadmap)

### 1. 엑셀 연동 메이플 가계부 📊
- 결정석 수입, 큐브/스타포스 비용 등 게임 내 재화를 편리하게 기록하고 관리할 수 있도록 엑셀(`.xlsx`) 데이터 조작 및 연동 기능을 지원할 예정입니다.

### 2. 구글 드라이브 자동 동기화 ☁️
- 자택과 PC방 어디서나 가계부 데이터 및 개인 세팅 값을 연속성 있게 사용할 수 있도록 Google Drive API를 통한 클라우드 자동 업로드/동기화 기능을 지원할 예정입니다.
